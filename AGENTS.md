* My skills live in the `iExalt` plugin at `dotfiles/plugins/iExalt/skills/`, so both harnesses list them as `iExalt:<skill>`. When I request edits to skills, validate the changes. Reload Home Manager if skills were added, removed, or renamed; after any skill edit, run `scripts/install-codex-plugin.sh` (`./reload.sh` also runs it), because Codex loads a copy of the plugin. Then commit and push the scoped changes automatically unless I explicitly say otherwise.
* This repository is public, and so is its history. Keep personal information out of everything you commit, including commit messages and PR text: machine, host and device names, models, serials and other identifiers, IP addresses, private repository names, and session IDs. Put machine-specific facts a skill needs in an untracked file under `~/.config/<skill>/` and have the skill read it, asking me once if it's missing. Grep the diff for such details before committing, and squash any unpushed commit that contains them before pushing.
